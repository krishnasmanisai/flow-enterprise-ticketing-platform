# Changelog

All notable changes to this project will be documented in this file.

## [v0.8.0] - 2026-07-10

### Added
- **Enterprise Documentation Suite:** Created a comprehensive set of living documents in `/docs` to reflect product maturity.
- **Product Journal:** Documented core architectural and product decisions.

### Improved
- **Repository Presentation:** Upgraded `README.md` to act as a world-class SaaS landing page.
- **Global Filters:** Standardized the `DateRangeDropdown` across Dashboard and Tasks modules.

### Changed
- Reorganized folder structure and finalized the Design System documentation.

### Fixed
- Resolved missing imports in `Tasks.tsx` leading to compilation failures.
- Fixed layout overflows in `ClientConfiguration.tsx` on mobile devices.
