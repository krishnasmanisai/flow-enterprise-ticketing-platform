# Contributing to Flow Enterprise Support

First off, thank you for considering contributing to Flow Enterprise Support! It's people like you that make Flow such a great tool for enterprise teams.

## 1. Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check our [Issues](../../issues) first. If it doesn't exist, feel free to open a new issue.

## 2. Fork & create a branch

If this is something you think you can fix, then fork Flow Enterprise Support and create a branch with a descriptive name.

## 3. Implement your fix or feature

At this point, you're ready to make your changes. Feel free to ask for help; everyone is a beginner at first.

- **Follow the Design System:** Check `docs/DESIGN_SYSTEM.md` before adding new UI elements.
- **Update Documentation:** Any code change MUST be accompanied by updates to the relevant documentation (`README.md`, `CHANGELOG.md`, `ROADMAP.md`, etc.).

## 4. Make a Pull Request

At this point, you should switch back to your master branch and make sure it's up to date with Flow Enterprise Support's master branch.
